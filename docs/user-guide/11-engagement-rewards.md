# Module 11 — Engagement & Rewards

## What is this module for?

Earn points for daily work, share knowledge, and recognize colleagues.

---

## My Rewards

**Purpose:** See your points, level, and recent awards.

**Menu:** Rewards & Engagement → My Rewards

---

## Leaderboard

**Purpose:** Compare monthly points with colleagues.

**Menu:** Rewards → Leaderboard

---

## Send Cheer

**Purpose:** Recognize a colleague with peer points.

**Menu:** Rewards → Send Cheer

### Add (create new)

**Steps:**

1. Pick colleague.
2. Write a short thank-you.
3. Send.

---

## Submit Reward Claim

**Purpose:** Lead/Admin: submit delivery, innovation, social, and other approval-based activities for team members.

**Menu:** Rewards → Submit Claim

### Add (create new)

**Steps:**

1. Pick activity.
2. Select team member(s).
3. Add notes → Submit for approval.

---

## Reward Approvals

**Purpose:** Approve or reject pending point claims.

**Menu:** Rewards → Approvals

### Edit (update existing)

**Steps:**

1. Approve or Reject each pending row.

---

## Office Closing Checklist

**Purpose:** Daily closing checklist submission (+30 points).

**Menu:** Rewards → Office Closing

### Add (create new)

**Steps:**

1. Confirm date.
2. Submit checklist once per day.

---

## Reward Rules (admin)

**Purpose:** Configure automatic point rules and manual grants.

**Menu:** Rewards → Reward Rules

### Add (create new)

**Steps:**

1. Set trigger event, points, and conditions.
2. Save.

### Edit (update existing)

**Steps:**

1. Open rule → Edit → Save.

### Delete / remove

**How:**

1. Disable rule from edit screen (set Active = No).

---

## Knowledge Base

**Purpose:** Publish how-to articles; earn points when published.

**Menu:** Knowledge Base

### Add (create new)

**Steps:**

1. Write title and body.
2. Set status Published → Save.

### Edit (update existing)

**Steps:**

1. Edit article → Update → Save.

---

## Helpdesk

**Purpose:** Raise and resolve internal support tickets.

**Menu:** Helpdesk

### Add (create new)

**Steps:**

1. Subject and description → Submit.

### Edit (update existing)

**Steps:**

1. Manager: assign and set status Resolved.

---

## Events

**Purpose:** Company workshops and town halls calendar.

**Menu:** Events

### Add (create new)

**Steps:**

1. Title, date/time, location → Save.

### Edit (update existing)

**Steps:**

1. Edit event details from admin list.

---

## Certifications

**Purpose:** Submit external certs for manager approval and points.

**Menu:** Certifications

### Add (create new)

**Steps:**

1. Enter cert name and evidence URL.
2. Submit for approval.

### Edit (update existing)

**Steps:**

1. Manager approves or rejects from list.

---

## Customer Feedback

**Purpose:** Log structured client feedback linked to projects.

**Menu:** Customer Feedback

### Add (create new)

**Steps:**

1. Client, rating, feedback text → Save.
