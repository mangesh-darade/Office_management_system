# Module 03 — Attendance & Leave

## What is this module for?

Record daily punch in/out, request time off, approve team leave, and log timesheets.

![Animated overview — Attendance & Leave](videos/03-attendance-leave/attendance-tour-voiced.webm)


---

## Attendance

**Purpose:** Daily punch in and punch out with optional location or face check.

**Menu:** User Management → Attendance

![Video — Attendance](videos/03-attendance-leave/attendance-tour-voiced.webm)


![View list — Attendance](images/03-attendance-leave/attendance.png)


### Add (create new)

![Add screen — Attendance](images/03-attendance-leave/attendance-add.png)


**Steps:**

1. Admin: Mark Attendance.
2. Pick employee, date, in/out times.
3. Save.

### Edit (update existing)

![Edit screen — Attendance](images/03-attendance-leave/attendance-edit.png)


**Steps:**

1. Admin: open record → Edit.
2. Fix punch times → Save.

### Delete / remove

**How:**

1. Admin delete from attendance edit or list.

---

## Apply leave

**Purpose:** Request casual, sick, WFH, or other leave types.

**Menu:** Leave → Apply Leave

![Video — Apply leave](videos/03-attendance-leave/leave-apply-tour-voiced.webm)


![View list — Apply leave](images/03-attendance-leave/leave-apply.png)


### Add (create new)

**Steps:**

1. Fill type, dates, reason.
2. Submit → manager notified.

### Edit (update existing)

![Edit screen — Apply leave](images/03-attendance-leave/leave-edit.png)


**Steps:**

1. My Leaves → open pending request → Edit.

### Delete / remove

**How:**

1. My Leaves → Delete while status is Pending only.

---

## My leaves

**Purpose:** Track your leave request status.

**Menu:** Leave → My Leaves

![Video — My leaves](videos/03-attendance-leave/leave-crud-voiced.webm)


![View list — My leaves](images/03-attendance-leave/leave-my.png)


---

## Team leaves

**Purpose:** Managers approve or reject team leave requests.

**Menu:** Leave → Team Leaves

![View list — Team leaves](images/03-attendance-leave/leave-team.png)


### Edit (update existing)

**Steps:**

1. Open request → Approve or Reject with comment.

---

## Leave calendar

**Purpose:** See who is off on which days.

**Menu:** Leave → Calendar

![View list — Leave calendar](images/03-attendance-leave/leave-calendar.png)


---

## Timesheets

**Purpose:** Log hours against projects separately from attendance punch.

**Menu:** Project → Timesheets

![View list — Timesheets](images/03-attendance-leave/timesheets.png)


### Add (create new)

**Steps:**

1. Add row with project, task, hours.
2. Submit for approval if required.

### Edit (update existing)

**Steps:**

1. Edit entry before approval.

### Delete / remove

**How:**

1. Delete draft entries from timesheet list.
