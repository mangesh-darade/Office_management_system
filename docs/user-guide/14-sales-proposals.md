# Module 14 — Sales — Subscription Builder & Proposals

## What is this module for?

Build ElintOm subscription proposals and download or re-export saved proposal files.

---

## Subscription Builder

**Purpose:** Configure plan, industry, country, and chargeable add-ons, then preview or export a client proposal.

**Menu:** Sales → Subscription Builder

### How to use

**Steps:**

1. Open Sales → Subscription Builder.
2. Select plan, industry, and country.
3. Set client name/business and add-on quantities.
4. Use Preview Proposal, or Export as PDF / Excel / Word.

---

## ElintOm Proposals

**Purpose:** Browse saved proposals and export each file as PDF, Excel, or Word.

**Menu:** Sales → ElintOm Proposals

### How to use

**Steps:**

1. Open Sales → ElintOm Proposals.
2. Review client, business, creator, and date columns.
3. Use Export → PDF, Excel, or Word (DOC) for a row.
4. Excel/Word need a proposal re-saved from Subscription Builder if the HTML source is missing.
