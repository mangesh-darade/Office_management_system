# Module 10 — Administration

## What is this module for?

System settings, permissions, email, holidays, activity log, and database tools.

![Animated overview — Administration](videos/10-admin/settings-tour-voiced.webm)


---

## System settings

**Purpose:** Company info, attendance rules, leave, security, AI keys.

**Menu:** Settings → System Settings

![Video — System settings](videos/10-admin/settings-tour-voiced.webm)


![View list — System settings](images/10-admin/settings.png)


### Edit (update existing)

**Steps:**

1. Change tab → edit values → Save.

---

## Permissions

**Purpose:** Tick which modules each role can access.

**Menu:** Settings → Permission Manager

![View list — Permissions](images/10-admin/permissions.png)


### Edit (update existing)

**Steps:**

1. Select role → tick modules → Save.
