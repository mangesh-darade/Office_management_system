# Module 13 — Sales — EBA Platform

## What is this module for?

Run the ElintOm Business Assessment (EBA) ROI calculator from Sales — fully client-side, no server save.

---

## EBA Platform

**Purpose:** Open the ROI assessment tool to model leakage and savings for a prospect. Calculations stay in the browser.

**Menu:** Sales → EBA Platform

### How to use

**Steps:**

1. Open Sales → EBA Platform.
2. Fill assessment sections (workforce, inventory, billing, sales, purchase, owner time).
3. Review sticky ROI summary at the bottom.
4. Use Open full screen if you need a larger workspace.
